Universal Keybindings ⌨️ ​

Core keybindings across Niri, Ghostty, Zellij, and Helix in Solar.

🌊 Niri Scrollable Wayland Compositor ​

The default modifier key is Mod (Super / Windows).

Window & Column Management ​

ActionKeybinding
Focus Left / RightMod + H / L (or ← / →)
Focus Up / Down (in column)Mod + J / K (or ↓ / ↑)
Move Window Left / RightMod + Shift + H / L
Move Window Up / DownMod + Shift + J / K
Close WindowMod + Q (or Mod + Shift + C)
Fullscreen ToggleMod + F
Center ColumnMod + C
Expand / Shrink WidthMod + R / Mod + Shift + R

Workspace & Monitors ​

ActionKeybinding
Switch Workspace 1–8Mod + 1–8
Move Column to Workspace 1–8Mod + Shift + 1–8
Move Focus to Left/Right MonitorMod + Ctrl + H / L

Application Launchers & System ​

ActionKeybinding
Terminal (Ghostty)Mod + Enter (or Mod + T)
App Launcher (Fuzzel / Rofi)Mod + Space (or Mod + D)
Interactive ScreenshotPrintScreen or Mod + Shift + S
Lock ScreenMod + Alt + L

⚡ Ghostty Terminal ​

ActionKeybinding
New TabCtrl + Shift + T
Split HorizontallyCtrl + Shift + D
Split VerticallyCtrl + Shift + E
Navigate SplitsCtrl + Alt + H/J/K/L

📝 Helix Modal Editor ​

ActionKeybinding
File PickerSpace + f
Global Text SearchSpace + /
Buffer / Open TabsSpace + b
Save File:w + Enter or Space + w
Quit:q + Enter
